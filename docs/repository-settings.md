# Repository settings

Some project settings live in GitHub metadata and cannot be represented by the source tree.

Recommended repository topics:

```text
java
kotlin
jvm
application-errors
error-handling
outcomes
http
grpc
microservices
```

Keep Issues enabled. Discussions are not required until there is enough external usage to justify a second support channel.

Use squash or rebase merges for normal development and delete merged branches when practical. Protect `main` with the CI, CodeQL, and dependency-review checks used by this repository.
